# Candlestick Chart Engine & Paper-Trading Simulator

## About the Project
The Candlestick Chart Engine & Paper-Trading Simulator is a browser-based educational application that helps users understand stock price movements and practice virtual trading without using real money.

## Features
- Interactive candlestick chart visualization
- Green and red candles for price movements
- Moving Average indicator
- Support and Resistance levels
- Multiple timeframes: 1, 5, 15, 30 minutes and 1 hour
- Automatic price updates
- Zoom in, zoom out, and reset zoom controls
- Virtual BUY and SELL transactions
- Portfolio balance and holdings tracking
- Profit and Loss (P&L) calculation
- Transaction history
- LocalStorage for saving trading data

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Canvas API
- Fetch API
- JSON
- LocalStorage

## How to Run Locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Purpose
This project provides a practical way to learn candlestick charts, basic technical indicators, and paper-trading concepts in a simulated environment.

## Disclaimer
This application is for educational purposes only. It does not execute real stock market trades or provide financial advice.
